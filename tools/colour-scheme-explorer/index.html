Colour scheme explorer

How to use

Start from one colour and rotate it around the hue wheel: complementary, analogous, triadic and friends. Each scheme says why it holds together, and any pair can be checked for real WCAG contrast before it ships.

01 / Make a palette

Find colours that belong together

Every scheme is a set of fixed angles on the ring. Spin the base hue and the others follow.

  • #c2452dred
  • #2daac2cyan

Two colours opposite on the wheel. One carries attention, the other supports it. Hue opposition does not guarantee readable text; check the measured contrast ratio.

What this check covers

Schemes come from hue rotation at fixed saturation and lightness (monochromatic steps lightness instead). The contrast check is the WCAG 2.x ratio over sRGB relative luminance, assuming opaque colours on a calibrated display; it does not cover colour blindness, anti-aliasing, or brand judgement. A passing pair can still look wrong; a failing pair can be fine for decorative elements that carry no information.

Read: WCAG 2.1, contrast minimum
