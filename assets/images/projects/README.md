## Concept illustrations

`streaming-illustration.svg` and `sentiment-illustration.svg` embed compressed, AI-generated artwork made for these cards. Cyan music tiles and a record suggest streaming; amber conversation bubbles and a prism suggest sentiment classification. Both are labelled as concept illustrations on the page. They are not real dashboards, measurements, architecture diagrams or model output. The original simplified flow SVGs remain in the repository but are no longer used on the cards. The real colorization output is unchanged.
