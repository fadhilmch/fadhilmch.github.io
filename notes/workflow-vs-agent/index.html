Workflow or agent

Agent design178 words5 outgoing2 backlinks

Ask one question: who decides the next step? If code decides, it is a workflow, even when every step calls a model. If the model decides, it is an agent. A model that classifies (“in scope?”) while code routes on the answer is still a workflow, the routing pattern.

Defaults:

  • If you can draw the flow before you see the input, write it as a workflow.
  • A choice from a fixed list is one call with [[structured-output]] plus an if, not an agent.
  • Give the model the path only when the number of steps depends on results you can’t predict. Then set a [[loop-budget]].

Gotchas:

  • A class named “agent” that never calls a model is a function. Name it one.
  • AutoGen’s SelectorGroupChat asks a model when your selector_func returns None. In a fixed flow, raise instead, so a missing case fails loudly and shows up in [[traces]].
  • A cleaner orchestrator does not make generation faster.

Next: [[single-agent-first]], [[multi-agent]]. Read the full example: From a multi-agent group chat to one agent with fixed steps.

Reference: Anthropic, Building effective agents.
