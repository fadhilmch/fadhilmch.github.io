2e:T6e5,<p>A golden set pairs questions with expected answers and source references. In the design described in the post, simulated personas propose document-anchored candidates, but people approve them before they count. Generated text is a proposal, not ground truth, and changing documents can make a once-good record stale.</p>
<p>One record wants at least:</p>
<pre><code class="hljs language-json"><span class="hljs-punctuation">{</span>
  <span class="hljs-attr">"question"</span><span class="hljs-punctuation">:</span> <span class="hljs-string">"How do I reset a staging deploy?"</span><span class="hljs-punctuation">,</span>
  <span class="hljs-attr">"expected_answer"</span><span class="hljs-punctuation">:</span> <span class="hljs-string">"..."</span><span class="hljs-punctuation">,</span>
  <span class="hljs-attr">"sources"</span><span class="hljs-punctuation">:</span> <span class="hljs-punctuation">[</span><span class="hljs-string">"runbook-deploy#staging"</span><span class="hljs-punctuation">]</span><span class="hljs-punctuation">,</span>
  <span class="hljs-attr">"approved_by"</span><span class="hljs-punctuation">:</span> <span class="hljs-string">"person, not the generator"</span><span class="hljs-punctuation">,</span>
  <span class="hljs-attr">"reviewed_at"</span><span class="hljs-punctuation">:</span> <span class="hljs-string">"2026-10-01"</span>
<span class="hljs-punctuation">}</span>
</code></pre>
<p>Gotchas: anchor every record to a source document or you cannot detect staleness; re-review when the underlying docs change; and keep the set out of the training/prompt path - a leaked golden set measures memorization, not quality.</p>
